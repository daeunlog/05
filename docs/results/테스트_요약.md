# URL 위험도 분류 모델 테스트 결과

5조 · 2026년 11월 14일

## 1. 테스트 데이터

모델은 Kaggle의 Malicious URLs 데이터셋으로 학습했고, 테스트에는 아래 다섯 가지 데이터를 사용했다. 외부 데이터에서는 학습 데이터에 나온 도메인을 모두 제외했다.

| 데이터 | 건수 | 확인한 내용 |
|---|---|---|
| Malicious URLs 테스트 세트 | 94,921 | 학습 데이터와 같은 출처에서의 4종 분류 성능 |
| PhiUSIIL (UCI) | 198,471 | 다른 출처 데이터에서의 정상/피싱 구분 |
| Tranco 상위 사이트 | 9,093 | 유명 사이트 메인 주소의 오탐 여부 |
| OpenPhish | 275 | 최근(11월 12일 수집) 피싱 탐지 여부 |
| JPxxx holdout | 40,000 | 학습에 없던 도메인에서의 성능 (v5만 측정) |

테스트 세트의 클래스 구성은 정상 63,589건, 피싱 13,489건, malware 3,547건, defacement 14,296건이다. PhiUSIIL은 정상 125,007건, 피싱 73,464건이다.

## 2. 테스트 방법

전체 데이터 632,812건을 학습 70%, 검증 15%, 테스트 15%로 나눴다. 이때 URL 단위가 아니라 도메인 단위로 나눠서 같은 사이트의 주소가 학습과 테스트에 함께 들어가지 않게 했다.

모델 선택과 위험 등급 기준값은 검증 세트만 보고 정했다. 테스트 세트와 외부 데이터는 모든 설정을 마친 뒤 한 번만 평가했다.

악성 여부는 두 가지 기준으로 계산했다. 첫째는 4개 클래스 중 확률이 가장 높은 것을 답으로 보는 방식이고, 둘째는 위험 점수가 '주의' 등급 기준 이상이면 악성으로 보는 방식이다. '주의' 기준은 검증 세트에서 악성 URL의 99%가 걸리도록 정했다.

OpenPhish처럼 건수가 적은 데이터는 95% 신뢰구간을 같이 적었다. 또 학습 환경(GPU)과 서버용 추론 코드(CPU)에 같은 URL 500개를 넣어 결과가 같은지 확인했다.

## 3. 최종 모델(v3) 결과

테스트 세트 94,921건 기준이다.

| 지표 | 값 |
|---|---|

| Macro F1 | 0.821 |
| 정상 URL 오탐률 | 19.6% (등급 기준 33.1%) |
| 악성 URL 미탐률 | 3.1% (등급 기준 1.0%) |

| 클래스 | Precision | Recall | F1 |
|---|---|---|---|
| 정상 | 0.982 | 0.804 | 0.884 |
| 피싱 | 0.530 | 0.903 | 0.668 |

| defacement | 0.840 | 0.946 | 0.890 |

| | 정상 | 피싱 | malware | defacement |
|---|---|---|---|---|
| 정상 | 51,130 | 9,931 | 395 | 2,133 |

악성 URL은 대부분 잡아냈지만 정상 URL의 약 20%를 악성으로 판정했다. 오탐의 대부분은 정상 URL을 피싱으로 분류한 경우(9,931건)다.

## 4. 버전별 비교

| 지표 | v2 | v3 | v4 | v5 |
|---|---|---|---|---|
| 테스트 Accuracy | 0.843 | 0.842 | 0.795 | 0.809 |
| 테스트 Macro F1 | 0.826 | 0.821 | 0.785 | 0.789 |
| 테스트 정상 오탐률 | 19.7% | 19.6% | 24.2% | 19.5% |
| 테스트 악성 미탐률 | 2.8% | 3.1% | 8.2% | 14.6% |
| PhiUSIIL AUROC | 0.43 | 0.43 | 0.85 | 0.87 |
| PhiUSIIL 정상 오탐률 | 99.2% | 98.6% | 25.5% | 10.1% |
| PhiUSIIL 악성 미탐률 | 4.3% | 7.1% | 20.9% | 31.5% |
| Tranco 오탐률 | 24.1% | 7.0% | 39.9% | 23.2% |
| OpenPhish 미탐률 | 7.3% | 11.3% | 4.7% | 5.8% |
| URL 1개 처리 시간 (CPU) | 5.3ms | 5.2ms | 5.5ms | 5.0ms |

각 버전에서 바꾼 점은 다음과 같다. v2는 URL 앞의 http(s)://와 www.를 지우고 학습한 기본 모델이다. v3는 정상 사이트의 메인 주소 35,659건을 학습에 추가했다. v4는 메인 주소 끝의 '/'까지 지워 입력 형식을 맞췄다. v5는 다른 출처(Common Crawl)의 정상 URL 20만 건을 추가로 학습했다.

v2와 v3의 Tranco 결과는 주소 끝 '/' 유무의 영향을 받은 것으로 보여 v4, v5와 바로 비교하기는 어렵다. OpenPhish는 275건뿐이라 버전 간 차이가 신뢰구간 안에 있다.

## 5. 정리

학습 데이터와 같은 출처에서는 v3의 성능이 가장 고르게 나와 최종 모델로 정했다. 다만 다른 출처의 정상 URL을 거의 대부분 악성으로 판정하는 문제가 있다. v4와 v5는 이 문제를 줄였지만 대신 피싱을 더 많이 놓쳤다.

따라서 서비스에서는 AI 점수만으로 차단하지 않고 VirusTotal 등 외부 검사 결과와 함께 판단하도록 할 예정이다.
